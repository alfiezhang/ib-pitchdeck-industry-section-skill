# template production scripts

Template analysis and fit tools. Template validators are owned by QC.

Use these only when the template role or a QC repair brief names the exact tool. Do not browse this folder as a workflow menu.

Scripts:
- `check_registry_coverage.py`
- `check_slide_registry.py`
- `check_template_tokens.py`
- `extract_template_registry.py`
- `generate_text_fit_rules.py`
- `template_analyzer.py`
- `template_fit.py`
