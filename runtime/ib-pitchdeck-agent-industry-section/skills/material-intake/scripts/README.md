# material-intake production scripts

Material parsing and intake production tools. Intake validators are owned by QC.

Use these only when the material-intake role or a QC repair brief names the exact tool. Do not browse this folder as a workflow menu.

Scripts:
- `build_material_extracts_skeleton.py`
- `build_material_manifest.py`
- `extract_excel_text.py`
- `extract_pdf_text.py`
- `extract_pptx_text.py`
- `extract_web_url.py`
- `ingest_materials.py`
- `source_classification.py`
