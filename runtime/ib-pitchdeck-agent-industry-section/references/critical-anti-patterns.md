# Critical Anti-Patterns

Use this file when a filled deck looks technically complete but still feels wrong. The point is to sharpen judgment, hierarchy, and visual finish.

## Placeholder-Looking Pages

A replaced token box is not automatically a finished design. If the slide looks like text was dropped into temporary boxes, the hierarchy has failed. Titles, takeaways, body modules, exhibits, and source notes should read as different levels of information.

Respect the template's hierarchy and house style; use them to make the page clearer, not to flatten the content into blocks of similar text.

If the user-provided template includes colored instruction boxes, sample columns, or example text, treat them as guidance about content intent. Remove or restyle instruction-like elements in the final page; do not preserve placeholder colors, placeholder contrast, or sample column count unless the user explicitly requested strict layout.

Review pattern:

- Symptom: the final slide still looks like a worksheet, placeholder, or instruction page.
- Risk: the client sees process scaffolding instead of a finished banker page.
- Repair: keep the template's theme and hierarchy, but redraw the content as a finished exhibit, table, card set, or body module.

## Generic Bullet Flattening

Driver cards, barrier modules, value-chain stages, comparison rows, and left/right panels are not interchangeable containers. Each should carry a distinct role. If every box could swap places with every other box, the page has lost its banker structure.

Keep structured pages structured: drivers should be drivers, value-chain stages should be stages, profit-pool panels should show economics, and source notes should remain source notes.

Review pattern:

- Symptom: every body block has the same tone, length, and evidence role.
- Risk: the slide feels padded even when it contains many words.
- Repair: give each module a distinct job, such as driver, mechanism, benchmark, caveat, or project relevance bridge.

## Repetition

Repeated paraphrases make the slide feel padded. Adjacent cards or panels should move the argument forward: different mechanism, different evidence, different comparison, or different caveat.

If two boxes say nearly the same thing, rewrite one or remove it.

## Role Drift

Do not move content into a weaker visual role just because another area of the slide has more room. A takeaway should not become a body bullet; a source footer should not become vague; project-context language should not sit inside a market-facts field.

If the intended visual role is crowded, preserve the role and choose a cleaner layout: tighter copy, a split page, or a redesigned module.

## Weak Source Footers

Source footers are part of the argument. A page with market data or hard claims needs source specificity. `Source: public information` is not enough for load-bearing claims.

Keep the most important sources, preserve date/scope where material, and treat a missing or vague source footer as a quality problem.

## Silent Truncation

Text that is cut off is not a small formatting issue; it can remove the caveat or source detail that makes the page defensible. If text is incomplete, rewrite and regenerate the PPT. If repeated attempts still overflow, change the page design rather than accepting broken output.

## Fact, Inference, And Management View

Sourced facts, banker inferences, and management-provided views should not sound equally certain. Target advantage, market structure, or transaction relevance needs attribution and caveats when evidence is thin.

Keep factual claims sourced, keep inferences modest, and keep management-only claims clearly labeled.

## Sparse Exhibits

A formal page should not rely on one oversized bar, an empty chart area, or three short bullets when it needs a real exhibit. A single datapoint rarely carries an investment-banking page. When evidence is limited, use a caveated table, KPI card set, or source-labeled grid so the page still feels structured and honest.

Review pattern:

- Symptom: the slide has no visual center of gravity or only one isolated number.
- Risk: the deck looks empty and generic even if the headline is directionally right.
- Repair: use comparable data when available; otherwise use cards, a labeled source table, or a qualitative structure that makes the evidence limits clear.

## Number Drift

The same metric should not change silently across pages. If market size, growth, share, GMV, unit sales, or margin appears more than once, the value, unit, period, geography, and source label should reconcile. If a number changes because the scope changes, label the scope difference visibly.

Review pattern:

- Symptom: repeated figures use different values, units, periods, or source labels without explanation.
- Risk: one stale or mismatched number weakens the whole client deck.
- Repair: reconcile the source metric in the evidence DB or revise the page copy so each visible number has the correct scope and source.
